# TryHackMe

## 실습 환경
- Oracle VirtualBox
- kali-linux 2026.2 virtualbox
- firefox
- burpsuite
- tryhackme vpn

## 진행사항
| Room | 주제 | 진행률 |
|-------|------|-------------|
| [ignite](./ignite.md) | `Web`, `Privesc` | `██████████` 100% |

> 진행률은 풀이 문서를 작성한 섹션 기준
> 플래그, 비밀번호 등 민감한 값은 문서에서 마스킹 처리함 (대상 IP는 TryHackMe VPN이 할당하는 임시 사설 IP로 노출 영향 없음)
